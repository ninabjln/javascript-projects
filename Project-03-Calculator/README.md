# Calculator

A simple calculator built with **HTML, CSS, and JavaScript**.

This project was created to practice JavaScript functions, string manipulation, DOM manipulation, and `localStorage`.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers
- Calculate results using `=`
- Clear calculation
- Saves the current calculation using `localStorage`
- Keeps the calculation after refreshing the page

## Technologies

- HTML5
- CSS3
- JavaScript

## What I Practiced

- Functions and parameters
- String concatenation
- DOM manipulation
- `querySelector()`
- `localStorage`
- `eval()`
- Template literals
- Event handling with `onclick`

## How It Works

The calculator stores the current calculation as a string.

For example:

```text
10 + 5 * 2
```

When `=` is pressed, the expression is evaluated and the result is displayed.

The current calculation is also saved to `localStorage`, allowing it to remain after refreshing the page.
